## Validation and activation

237 Flagship tests pass, plus JavaScript/manifest syntax checks. The tests execute actual Apps Script handlers against disposable Sheet mocks; this is not live write testing. Hi Service has its own audit and tests.

Frontend changes and cache bump are in this repo. To activate backend repairs, replace the complete shared Code.gs, Flagship Stock.gs, and Hi Service HiService.gs, then deploy a new version of the existing Apps Script /exec deployment. Apps Script deployment and mobile/PDF visual verification were not available through this execution environment. Supabase's separate RLS remains independent of Google Apps Script privileges. Google Sheets writes are not database transactions; movement preflight prevents validation-driven partial writes, but cannot guarantee rollback during a Google service outage.
